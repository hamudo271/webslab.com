1단계 상담 · 기획

전문 컨설턴트와의 홈페이지 제작에 대한 1:1 맞춤 컨설팅을 진행합니다.
프로젝트 진행이 확정되면 원하는 컨셉과 방향, 콘텐츠 등의 기획을 정의합니다.

고객준비해 주실 것
  • 제작 목적 · 타겟 · 사이트맵 정리
  • 참고 레퍼런스 사이트 2~3개
  • 희망 예산 · 오픈 일정 공유
웹스랩웹스랩이 하는 일

  • 사이트맵 · 페이지 구조 설계
  • 단계별 일정 및 체크리스트 제안

2단계 디자인 시안

작성한 기획안을 토대로 UI/UX를 고려한 메인 + 주요 서브 페이지 디자인 시안을 작업합니다.
PC·모바일 뷰를 함께 설계하고, 2회 수정이 기본 포함됩니다.

고객준비해 주실 것

  • 페이지별 텍스트 원고 확정

웹스랩웹스랩이 하는 일

홈페이지 준비자료

준비는 가볍게,
나머지는 웹스랩이 채웁니다

있는 것만 보내 주세요. 없는 것은 질문지와 웹스랩의 손으로 채웁니다. 무엇이 있는지 골라 보시면 준비 방법을 바로 알려드려요.

  1. 로고 원본

    AI · SVG · PNG 같은 원본 파일

    이렇게 보내 주세요

    배경이 없는 원본(AI·SVG·투명 PNG)이면 가장 좋아요. 명함이나 간판에 쓴 파일 그대로면 됩니다.

    웹스랩이 이렇게 해요

    회사 이름으로 먼저 메인 시안을 잡아 보여드려요. 로고는 상담 때 함께 정하면 됩니다.

  2. 소개 원고

    회사·서비스를 설명하는 글

    이렇게 보내 주세요

    메뉴별로 나누지 않아도 괜찮아요. 회사소개서나 기존 사이트 글을 그대로 보내 주시면 웹스랩이 페이지에 맞게 정리해요.

    웹스랩이 이렇게 해요

    질문지에 답만 해 주세요. 답을 바탕으로 웹스랩이 문장을 정리해 원고를 만듭니다.

  3. 사진

    매장 · 제품 · 시설 사진

    이렇게 보내 주세요

    원본 크기 그대로, 폴더에 넣어 한 번에 보내 주세요. 고르는 일은 웹스랩이 해요.

    웹스랩이 이렇게 해요

    정품 이미지 라이선스 30만 컷 이상에서 업종에 맞는 사진을 골라 써요. 추가 비용이 없어요.

  4. 메뉴 구조

    어떤 페이지가 필요한지

    이렇게 보내 주세요

    대메뉴와 하위 메뉴를 글로 적어 주시면 돼요. 예) 회사소개 › 인사말 · 오시는 길

    웹스랩이 이렇게 해요

    사이트맵과 페이지 구조는 상담 뒤 웹스랩이 설계해 제안드려요. 보시고 고치기만 하면 됩니다.

  5. 참고 사이트

    마음에 드는 사이트 2~3개

    이렇게 보내 주세요

    주소와 함께 "어느 부분이 좋았는지" 한 줄만 적어 주세요. 색, 분위기, 메뉴 구성 어떤 것이든 좋아요.

    웹스랩이 이렇게 해요

    계약 전에 메인 시안을 무료로 먼저 보여드려요. 시안을 보며 방향을 정하면 됩니다.

  6. 도메인 · 호스팅

    사이트 주소와 서버

    이렇게 보내 주세요

    오픈 전에 계정 정보만 공유해 주세요. 연결과 SSL 설정은 웹스랩이 해요.

    웹스랩이 이렇게 해요

    호스팅·도메인·SSL·메일까지 운영 환경을 웹스랩이 직접 세팅해 납품해요.

FAQ

자주 묻는 질문

비용·기간·운영까지, 상담 전에 많이 물어보시는 질문을 모았어요.

질문 더 보기

  • 프로젝트 규모와 페이지 수, 필요한 기능에 따라 달라집니다.

    회사소개와 문의 폼 정도의 기본적인 사이트는 견적이 비교적 단순하고, 회원가입·예약·관리자 기능처럼 별도 개발이 필요한 항목이 들어가면 미팅을 통해 범위를 함께 정리한 뒤 견적 책정이 필요합니다.

    어떤 사이트가 필요한지 아직 명확하지 않으셔도 괜찮습니다. 무료 상담을 통해 사이트 정의와 견적을 안내해 드립니다.

    상담하고 견적받기

  • 일반적인 기업 사이트는 약 4~6주, 복잡한 고기능 시스템·프로그램형은 8~12주 이상 소요됩니다.

    상담 단계에서 페이지와 기능을 함께 확정한 뒤 단계별 일정을 미리 공유드립니다.

    오픈 일자가 정해진 프로젝트라면 일정을 역산해 진행 가능 여부를 솔직하게 안내드립니다.

    제작 절차 자세히 보기

  • 처음 합의된 범위 안에서는 추가 비용이 발생하지 않습니다.

    다만 진행 중에 새 기능이 추가되거나 기획 방향이 크게 바뀌는 경우에는 별도 협의가 필요합니다.

    이때도 어떤 작업에 얼마가 추가되는지 사전에 명확히 안내드린 뒤, 동의를 받고 나서야 작업에 들어갑니다.

    사전 상담받기

  • 모든 사이트는 PC·태블릿·모바일 세 가지 화면 크기에 자연스럽게 맞춰지는 반응형으로 제작됩니다.

    단순히 화면이 줄어드는 수준이 아니라, 작은 화면에서도 메뉴·이미지·텍스트의 흐름이 어색하지 않도록 디바이스별로 따로 설계하고 실기기에서 검수합니다.

    반응형 홈페이지 체험하기

  • 모든 사이트에 검색 노출의 기본이 되는 셋업(페이지 제목·설명, 이미지 정보, 사이트맵, 구조화 데이터 등)을 기본 작업에 포함해 무료로 적용합니다.

    다만 특정 키워드의 상위 노출을 본격적으로 노리는 전략이나 정기적인 콘텐츠 발행은 별도 영역이라, 필요한 경우 목표와 예산을 함께 보고 따로 안내드립니다.

    전문 칼럼 보기

  • 사이트를 직접 관리하실 수 있도록 관리자 화면을 충분히 만들어 드리기 때문에 유지보수 계약은 필수가 아닌 선택입니다.

    운영 중 기능 개선이나 추가 개발이 필요한 경우에만 선택적으로 유지보수를 진행할 수 있습니다.

    콘텐츠 수정·기능 추가·보안 점검을 정기적으로 맡기고 싶으시다면 월 단위 구독형 유지보수도 운영 중이니, 운영 부담을 줄이고 싶은 경우에 검토해 보시면 됩니다.
